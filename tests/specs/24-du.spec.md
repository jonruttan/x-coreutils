# @weight 2

How du walks: what it does with a symlink (the last of -P, -H and -L), a file
with several names (counted once unless -l), a device other than the
operand's (-x), and a path it cannot read.  The expected text and statuses
are GNU du's for the same trees.

A block count is the file system's business, so the cases show which paths
du printed and whether a total is the sum it should be -- never the number.

## the fixtures

### a tree of links and names, and readers for what du said

`d` holds `big`, `sub/small`, `olk -> ../out` (which holds `far`),
`flk -> big` and `dead -> nowhere`; `top -> d`; `h/one` has a second name,
`h/two`.  `du` runs the applet and answers (STDOUT STDERR STATUS); `paths`
shows the paths it printed, and `blocks` is what a path holds itself.

```cu
(do (def dh (fn (_ n) (string-append "/tmp/x-cu-du/" n))) (def mk (fn (_) (proc-run (list "/bin/sh" "-c" "chmod -R u+rwx /tmp/x-cu-du 2>/dev/null; rm -rf /tmp/x-cu-du && mkdir -p /tmp/x-cu-du/d/sub /tmp/x-cu-du/out /tmp/x-cu-du/h && cd /tmp/x-cu-du && head -c 20000 /dev/zero > d/big && printf x > d/sub/small && head -c 50000 /dev/zero > out/far && head -c 30000 /dev/zero > h/one && ln h/one h/two && cd d && ln -s ../out olk && ln -s big flk && ln -s nowhere dead && cd .. && ln -s d top")))) (mk) (def du (fn (_ argv) (do (sys-dup2 1 9) (sys-dup2 2 8) (let ((oo (file-open-write (dh ".out"))) (ee (file-open-write (dh ".err")))) (do (sys-dup2 oo 1) (sys-dup2 ee 2) (def du-st (cu-run (pair "du" argv) "")) (sys-dup2 9 1) (sys-dup2 8 2) (file-close oo) (file-close ee) (list (file-read-all (dh ".out")) (Str8 replace "/tmp/x-cu-du/" "" (file-read-all (dh ".err"))) du-st)))))) (def lines (fn (_ s) (filter (fn (_ l) (> (byte-len l) 0)) (%cu-lines s)))) (def paths (fn (_ r) (display (string-append (%cu-join-with (map (fn (_ l) (Str8 replace "/tmp/x-cu-du/" "" (%cu-nth 1 (%cu-split-byte l 9)))) (lines (first r))) " ") "\n")))) (def says (fn (_ r) (do (display (%cu-nth 1 r)) (display "status ") (display (%cu-nth 2 r)) (newline)))) (def blocks (fn (_ p) (%cu-du-blocks (file-lstat-full (dh p))))) (def total (fn (_ r) (%cu-num-prefix (%cu-last (lines (first r)))))) (display "made"))
```
---
    made

## links

### told nothing, a link counts as itself and is not followed

```cu
(do (def r (du (list "-a" (dh "d")))) (paths r) (says r) (display (if (= (total r) (+ (blocks "d") (blocks "d/big") (blocks "d/sub") (blocks "d/sub/small") (blocks "d/olk") (blocks "d/flk") (blocks "d/dead"))) "the total is the tree's own" "the total counts more than the tree")) (newline))
```
---
```output
d/big d/dead d/flk d/olk d/sub/small d/sub d
status 0
the total is the tree's own
```

### -L follows every link, and does not count a file it has counted already

`flk` is `big` by another way, so it is not printed; a link pointing nowhere
cannot be followed, and du names it without a reason.

```cu
(do (def r (du (list "-a" "-L" (dh "d")))) (paths r) (says r))
```
---
```output
d/big d/olk/far d/olk d/sub/small d/sub d
du: cannot access 'd/dead'
status 1
```

### -H follows a link named on the command line, and no other

```cu
(do (def r (du (list "-a" "-H" (dh "top")))) (paths r) (says r) (def r (du (list (dh "top")))) (paths r) (says r))
```
---
```output
top/big top/dead top/flk top/olk top/sub/small top/sub top
status 0
top
status 0
```

### the last of the three wins

```cu
(do (def r (du (list "-a" "-L" "-P" (dh "d")))) (paths r) (says r))
```
---
```output
d/big d/dead d/flk d/olk d/sub/small d/sub d
status 0
```

### -L does not walk again into a directory it is inside

```cu
(do (proc-run (list "/bin/sh" "-c" "rm -rf /tmp/x-cu-du/c && mkdir -p /tmp/x-cu-du/c/sub && : > /tmp/x-cu-du/c/sub/f && cd /tmp/x-cu-du/c/sub && ln -s .. up")) (def r (du (list "-a" "-L" (dh "c")))) (paths r) (says r))
```
---
```output
c/sub/f c/sub c
status 0
```

## names and devices

### a file with two names counts once, and -l counts it under each

```cu
(do (def r (du (list "-a" (dh "h")))) (paths r) (display (if (= (total r) (+ (blocks "h") (blocks "h/one"))) "counted once" "counted twice")) (newline) (def r (du (list "-a" "-l" (dh "h")))) (paths r) (display (if (= (total r) (+ (blocks "h") (blocks "h/one") (blocks "h/two"))) "counted twice" "counted once")) (newline))
```
---
```output
h/one h
counted once
h/one h/two h
counted twice
```

### what several operands name is counted once between them

```cu
(do (def r (du (list "-s" (dh "h/one") (dh "h/two")))) (paths r) (def r (du (list "-s" (dh "d") (dh "d")))) (paths r) (def r (du (list "-s" "-l" (dh "h/one") (dh "h/two")))) (paths r))
```
---
```output
h/one
d
h/one h/two
```

### -x counts nothing on another device

`/dev` is a device of its own, reached here through a link that -L follows.

```cu
(do (proc-run (list "/bin/sh" "-c" "rm -rf /tmp/x-cu-du/x && mkdir -p /tmp/x-cu-du/x && ln -s /dev /tmp/x-cu-du/x/devs")) (def r (du (list "-a" "-L" "-x" (dh "x")))) (paths r) (says r))
```
---
```output
x
status 0
```

### a file named on the command line is printed without -a

```cu
(paths (du (list (dh "d/big"))))
```
---
    d/big

## what du cannot read

### a path that is not there

```cu
(do (def r (du (list (dh "nope")))) (paths r) (says r))
```
---
```output

du: cannot access 'nope': No such file or directory
status 1
```

### a directory whose entries it cannot read is counted for its own blocks

```cu
(do (proc-run (list "/bin/sh" "-c" "rm -rf /tmp/x-cu-du/u && mkdir -p /tmp/x-cu-du/u/in && : > /tmp/x-cu-du/u/in/f && chmod 000 /tmp/x-cu-du/u/in")) (def r (du (list (dh "u")))) (proc-run (list "/bin/sh" "-c" "chmod 755 /tmp/x-cu-du/u/in")) (paths r) (says r))
```
---
```output
u/in u
du: cannot read directory 'u/in': Permission denied
status 1
```
