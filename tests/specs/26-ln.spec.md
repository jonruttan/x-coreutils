# @weight 2

Where ln makes a link, and what it says when it cannot.  A NAME that is a
directory -- or a link to one -- takes the link inside it; -n takes a link to
a directory as the link it is, so it names a file.  A link refused is said in
ln's words and fails.  The expected text and statuses are GNU ln's for the
same files.

## the fixtures

### a directory of names, and readers for what is there

`dir1`, `dir2` and `realdir` are directories, `a` and `b` files, and
`lk -> dir1`.  `ln` runs the applet; `shape` says what a path is.

```cu
(do (def lh (fn (_ n) (string-append "/tmp/x-cu-ln/" n))) (def mk (fn (_) (proc-run (list "/bin/sh" "-c" "rm -rf /tmp/x-cu-ln && mkdir -p /tmp/x-cu-ln/dir1 /tmp/x-cu-ln/dir2 /tmp/x-cu-ln/realdir && cd /tmp/x-cu-ln && printf A > a && printf B > b && ln -s dir1 lk")))) (mk) (def ln (fn (_ argv) (do (sys-dup2 1 9) (sys-dup2 2 8) (let ((oo (file-open-write (lh ".out"))) (ee (file-open-write (lh ".err")))) (do (sys-dup2 oo 1) (sys-dup2 ee 2) (def ln-st (cu-run (pair "ln" argv) "")) (sys-dup2 9 1) (sys-dup2 8 2) (file-close oo) (file-close ee) (display (Str8 replace "/tmp/x-cu-ln/" "" (file-read-all (lh ".out")))) (display (Str8 replace "/tmp/x-cu-ln/" "" (file-read-all (lh ".err")))) (display "status ") (display ln-st) (newline)))))) (def shape (fn (_ p) (let ((k (file-lstat-kind (lh p)))) (match ((eq? k (lit link)) (string-append "-> " (file-readlink (lh p)))) ((eq? k (lit dir)) (string-concat (list "dir [" (%cu-join-with (%cu-walk-names (lh p)) " ") "]"))) ((eq? k (lit none)) "missing") (#t "file"))))) (def shapes (fn (_ ps) (display (string-append (%cu-join-with (map (fn (_ p) (string-concat (list p " " (shape p)))) ps) ", ") "\n")))) (display "made"))
```

## -n

### without -n, a link to a directory takes the new link inside it

```cu
(do (mk) (ln (list "-s" "dir2" (lh "lk"))) (shapes (list "lk" "dir1")))
```
---
```output
status 0
lk -> dir1, dir1 dir [dir2]
```

### -n takes it as the link it is: taken, until -f drops it

```cu
(do (mk) (ln (list "-s" "-n" "dir2" (lh "lk"))) (shapes (list "lk" "dir1")) (ln (list "-s" "-f" "-n" "dir2" (lh "lk"))) (shapes (list "lk" "dir1")))
```
---
```output
ln: failed to create symbolic link 'lk': File exists
status 1
lk -> dir1, dir1 dir []
status 0
lk -> dir2, dir1 dir []
```

### -b keeps the link it displaces, and -v says what was made

```cu
(do (mk) (ln (list "-s" "-f" "-b" "-n" "-v" "dir2" (lh "lk"))) (shapes (list "lk" "lk~")))
```
---
```output
'lk' -> 'dir2'
status 0
lk -> dir2, lk~ -> dir1
```

### a directory itself is one, -n or no -n

```cu
(do (mk) (ln (list "-s" "-n" "dir2" (lh "realdir"))) (shapes (list "realdir")))
```
---
```output
status 0
realdir dir [dir2]
```

## what ln cannot do

### a name that is taken

```cu
(do (mk) (ln (list "-s" "a" (lh "b"))) (ln (list (lh "a") (lh "b"))) (shapes (list "b")))
```
---
```output
ln: failed to create symbolic link 'b': File exists
status 1
ln: failed to create hard link 'b': File exists
status 1
b file
```

### a name in a directory that is not there, and a hard link to nothing

```cu
(do (mk) (ln (list "-s" "a" (lh "nodir/b"))) (ln (list (lh "nosuch") (lh "c"))) (shapes (list "c")))
```
---
```output
ln: failed to create symbolic link 'nodir/b': No such file or directory
status 1
ln: failed to access 'nosuch': No such file or directory
status 1
c missing
```

### several targets need a directory to go in

```cu
(do (mk) (ln (list "-s" "-n" "dir2" "a" (lh "lk"))) (ln (list "-s" "dir1" "dir2" (lh "a"))) (ln (list "-s" "dir1" "dir2" (lh "c"))) (shapes (list "dir1" "c")))
```
---
```output
ln: target 'lk': Not a directory
status 1
ln: target 'a': Not a directory
status 1
ln: target 'c': No such file or directory
status 1
dir1 dir [], c missing
```

### and so does -t, said its own way

```cu
(do (mk) (ln (list "-s" "-t" (lh "a") "b")) (ln (list "-s" "-t" (lh "nosuch") "b")) (ln (list "-s" "-n" "-t" (lh "lk") "b")) (ln (list "-s" "-t" (lh "lk") "b")) (shapes (list "dir1")))
```
---
```output
ln: target 'a' is not a directory
status 1
ln: failed to access 'nosuch': No such file or directory
status 1
ln: target 'lk': Not a directory
status 1
status 0
dir1 dir [b]
```
