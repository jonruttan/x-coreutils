# @weight 1

busybox's ps (procps/ps.c, built with DESKTOP), over the processes
x/sys/host reports.  The tables are checked against busybox's own code:
its column functions, format_time, smart_ulltoa4, read_cmdline's rules and
its header and row layout, compiled unchanged and run on the same five
processes these cases give.  A `|` marks the end of each line, so the
spaces a column keeps can be seen.  The runs at the end ask this machine.

## the fixtures

## the table

### the default columns: pid, user, time, args

args is the command line, [comm] when there is none, and {comm} before it
when the program's name does not start with comm; a control byte is `?`.

```cu
(ps-show "pid,user,time,args" ps-recs)
```
---
```output
PID   USER     TIME  COMMAND|
    1 root      0:04 [init]|
    7 54321     0:00 {worker} /usr/bin/python3 x.py|
    9 54321     1h05 -bash|
   42 54321     1h01 sh -c echo?hi|
   99 root      0:00 [kthreadd]|
```

### the number columns, stat, tty, the sizes and the elapsed time

stat is the state, W for no memory, and < or N for the nice; tty is
major,minor; vsz and rss are kilobytes in four characters.

```cu
(ps-show "pid,ppid,pgid,sid,nice,stat,tty,vsz,rss,etime,comm" ps-recs)
```
---
```output
PID   PPID  PGID  SID   NI    STAT TT     VSZ  RSS  ELAPSED COMMAND|
    1     0     1     1     0 S    ?      160m 8192  1:40   init|
    7     1     7     1     5 ZN   ?         0    0  0:59   worker|
    9     1     9     9   -20 R<   4,1    1.9g 9.9m  100d   bash|
   42     1    42    42    -5 R<   136,0     4    4  1d01   sh|
   99     2     0     0    19 SWN  ?         0    0  1h00   kthreadd|
```

### no header when every column's is empty

(ps-show "pid=,comm=" (List take 2 ps-recs))

### a field the kernel does not report prints `-`, as POSIX asks

A Darwin process of another user's, with no state, size, CPU time, start or
terminal: tty is busybox's `?`.

```cu
(ps-show "pid,stat,vsz,rss,time,etime,tty,comm" (list (ps-rec 500 1 500 500 0 0 0 0 () "launchd" () () 0 () () () () ())))
```
---
```output
PID   STAT VSZ  RSS  TIME  ELAPSED TT     COMMAND|
  500 -    -    -    -     -       ?      launchd|
```

### -o names, and their first six letters, the way busybox's find_out_spec does

```cu
(list (map first (%ps-parse-o (list "pid,comm" "rss"))) (map first (%ps-parse-o (list "rgroupX,stat"))) (%ps-parse-o (list "pid,bogus")))
```

## this machine

### ps: busybox's header, this process among the rows, and status 0

```cu
(let ((r (run-out (list "ps")))) (def lines (Str8 split "\n" (first r))) (def me (%cu-int->str (Sys getpid))) (list (first lines) (List any? (fn (_ l) (str=? me (Str8 trim (substring l 0 (if (< (byte-len l) 5) (byte-len l) 5))))) (rest lines)) (first (rest r)) (first (rest (rest r)))))
```
---
    ("PID   USER     TIME  COMMAND" #t "" 0)

### ps -o: this process's pid, ppid and user agree with the system's

```cu
(let ((r (run-out (list "ps" "-o" "pid,ppid,user")))) (def me (%cu-int->str (Sys getpid))) (def row (List find (fn (_ l) (str=? me (Str8 trim (substring l 0 5)))) (rest (Str8 split "\n" (first r))))) (def sys (sh-out (string-append "ps -o pid=,ppid=,user= -p " me))) (list (equal? (ps-words row) (ps-words sys)) (first (rest (rest r)))))
```
---
    (#t 0)
