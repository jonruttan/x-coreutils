# @weight 1

busybox's bc (miscutils/bc.c), read from a file or standard input, not a
terminal.  Every expectation is busybox 1.36.1's own output, less the banner
line its usage text starts with.  A `|` marks the end of each line written to
standard output.

## the fixtures

### the programs a.bc, e.bc, q.bc and r.bc, and a run of bc with standard input the text IN

```cu
(do (proc-run (list "/bin/sh" "-c" "rm -rf /tmp/x-cu-bc && mkdir -p /tmp/x-cu-bc")) (def bc-f (fn (_ n) (string-append "/tmp/x-cu-bc/" n))) (file-write-all (bc-f "a.bc") "1+1\n") (file-write-all (bc-f "e.bc") "1\n2+\n") (file-write-all (bc-f "q.bc") "7\nquit\n") (file-write-all (bc-f "r.bc") "x=read();x*2\n") (def bc-case (fn (_ in argv) (do (sys-dup2 1 9) (sys-dup2 2 8) (def st (let ((oo (file-open-write (bc-f "o"))) (ee (file-open-write (bc-f "e")))) (do (sys-dup2 oo 1) (sys-dup2 ee 2) (def rs (cu-run argv in)) (sys-dup2 9 1) (sys-dup2 8 2) (file-close oo) (file-close ee) rs))) (display (%str-concat (list (Str8 replace "\n" "|\n" (file-read-all (bc-f "o"))) "stderr:\n" (file-read-all (bc-f "e")) "status " (cu-int->str st) "\n")))))) (display "made"))
```
