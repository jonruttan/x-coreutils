# @weight 1

busybox's unzip (archival/unzip.c).  Every expectation is busybox's own
output, from a busybox built from its source, less the banner line its usage
text starts with; standard input reached it through a pipe, which it reads as
this reads standard input.  A `|` marks the end of each line written to
standard output, and a line it leaves open (a question) has none; `after:` is
what a command run after shows.

### a file where a directory goes; -d where it cannot go

```cu
(do (uz-case #t "-" "echo x > d" "@" (list "unzip" "-q" "a.zip")) (uz-case #t "-" "echo x > out" "@" (list "unzip" "-d" "out" "a.zip")))
```
---
```output
stderr:
unzip: can't stat 'd/': Not a directory
status 1
stderr:
unzip: can't change directory to 'out': Not a directory
status 1
```
