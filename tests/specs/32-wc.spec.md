# @weight 1

How wc lays out its rows.  Every row shares one column width: the digits
of what the regular files hold between them, and at least seven where any
input is not a regular file -- a pipe, a directory.  One count of one input
is not padded at all.  More than one input ends with a total, whose longest
line is the longest of them.  The expected text is GNU wc's for the same
files.

Standard input is a pipe here, since the runner's own is one.

## the fixtures

### files of known sizes

`a` holds one line of one word, `b` one line of two, and `big` 12351 bytes
over two lines.

```cu
(do (def wh (fn (_ n) (string-append "/tmp/x-cu-wc/" n))) (proc-run (list "/bin/sh" "-c" "rm -rf /tmp/x-cu-wc && mkdir -p /tmp/x-cu-wc/dd && cd /tmp/x-cu-wc && printf 'a\\n' > a && printf 'b b\\n' > b && head -c 12345 /dev/zero | tr '\\0' x > big && printf 'l1\\nl2\\n' >> big")) (def wc (fn (_ argv input) (do (sys-dup2 2 8) (let ((ee (file-open-write (wh ".err")))) (do (sys-dup2 ee 2) (def wc-st (cu-run (pair "wc" argv) input)) (sys-dup2 8 2) (file-close ee) (display (Str8 replace "/tmp/x-cu-wc/" "" (file-read-all (wh ".err")))) (display "status ") (display wc-st) (newline)))))) (display "made"))
```
---
    made

## the width

### files size the columns by what they hold between them

```cu
(wc (list (wh "big") (wh "a")) "")
```
---
```output
    2     2 12351 /tmp/x-cu-wc/big
    1     1     2 /tmp/x-cu-wc/a
    3     3 12353 total
status 0
```

### a pipe among them makes it seven

```cu
(wc (list (wh "a") "-") "x\n")
```
---
```output
      1       1       2 /tmp/x-cu-wc/a
      1       1       2 -
      2       2       4 total
status 0
```

### one count of one input is not padded; one count of two is

```cu
(do (wc (list "-c") "x\n") (wc (list "-l" (wh "a") (wh "b")) ""))
```
---
```output
2
status 0
1 /tmp/x-cu-wc/a
1 /tmp/x-cu-wc/b
2 total
status 0
```

### standard input that is a file is sized by what it holds

```cu
(do (sys-dup2 0 7) (let ((fd (file-open-read (wh "big")))) (do (sys-dup2 fd 0) (wc () (file-read-all (wh "big"))) (sys-dup2 7 0) (file-close fd) ())))
```
---
```output
    2     2 12351
status 0
```

## the total, and what wc cannot read

### -L's total is the longest line of them all

```cu
(wc (list "-L" (wh "a") (wh "big")) "")
```
---
```output
    1 /tmp/x-cu-wc/a
12347 /tmp/x-cu-wc/big
12347 total
status 0
```

### a file that is not there gets no row; a directory gets one, and makes it seven

What wc says of each comes in its turn: here, on its own stream, the
lines in order.

```cu
(wc (list (wh "nosuch") (wh "dd") (wh "a")) "")
```
---
```output
      0       0       0 /tmp/x-cu-wc/dd
      1       1       2 /tmp/x-cu-wc/a
      1       1       2 total
wc: nosuch: No such file or directory
wc: dd: Is a directory
status 1
```

### on one stream, each failure comes in its turn, after a directory's row

```cu
(do (sys-dup2 1 9) (sys-dup2 2 8) (let ((both (file-open-write (wh ".both")))) (do (sys-dup2 both 1) (sys-dup2 both 2) (cu-run (list "wc" (wh "nosuch") (wh "dd") (wh "a")) "") (sys-dup2 9 1) (sys-dup2 8 2) (file-close both) (display (Str8 replace "/tmp/x-cu-wc/" "" (file-read-all (wh ".both")))) ())))
```
---
```output
wc: nosuch: No such file or directory
      0       0       0 dd
wc: dd: Is a directory
      1       1       2 a
      1       1       2 total
```

### cleanup

```cu
(do (proc-run (list "/bin/sh" "-c" "rm -rf /tmp/x-cu-wc")) (display "clean"))
```
