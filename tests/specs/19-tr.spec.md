# @weight 2

tr's sets: the character classes, the bracket forms, and what it refuses.  The
expected bytes are GNU tr's for the same sets, shown as the hex od prints so a
byte is checked by a tool outside this bundle.

The input is the same throughout: "aB3 ." and a tab, then "z~" and a newline --
a letter of each case, a digit, a space, a punctuation mark, a control
character and a printable byte at the top of the range.

## the fixtures

### a scratch directory, and a reader for output as hex

```cu
(do (proc-run (list "/bin/sh" "-c" "rm -rf /tmp/x-cu-tr && mkdir -p /tmp/x-cu-tr")) (def hx (fn (_ argv input) (do (sys-dup2 1 9) (sys-dup2 2 8) (let ((o (file-open-write "/tmp/x-cu-tr/.out")) (e (file-open-write "/tmp/x-cu-tr/.err"))) (do (sys-dup2 o 1) (sys-dup2 e 2) (def hx-st (cu-run argv input)) (sys-dup2 9 1) (sys-dup2 8 2) (file-close o) (file-close e) (proc-run (list "/bin/sh" "-c" "od -An -tx1 -v /tmp/x-cu-tr/.out | tr -s ' \\n' ' ' | sed 's/^ //; s/ $//' > /tmp/x-cu-tr/.hex")) (display (file-read-all "/tmp/x-cu-tr/.hex")) (display " | ") (display (file-read-all "/tmp/x-cu-tr/.err")) (display "status ") (display hx-st) (newline)))))) (def in (bytes->str (list 97 66 51 32 46 9 122 126 10))) (display "made"))
```
---
    made

## the character classes

### [:lower:] and [:upper:] translate a case into the other

```cu
(do (hx (list "tr" "[:lower:]" "[:upper:]") in) (hx (list "tr" "[:upper:]" "[:lower:]") in))
```
---
```output
41 42 33 20 2e 09 5a 7e 0a | status 0
61 62 33 20 2e 09 7a 7e 0a | status 0
```

### -d takes the bytes a class holds

```cu
(do (hx (list "tr" "-d" "[:digit:]") in) (hx (list "tr" "-d" "[:space:]") in) (hx (list "tr" "-d" "[:punct:]") in) (hx (list "tr" "-d" "[:alnum:]") in) (hx (list "tr" "-d" "[:cntrl:]") in))
```
---
```output
61 42 20 2e 09 7a 7e 0a | status 0
61 42 33 2e 7a 7e | status 0
61 42 33 20 09 7a 0a | status 0
20 2e 09 7e 0a | status 0
61 42 33 20 2e 7a 7e | status 0
```

### [:punct:] holds every printable byte that is neither alphanumeric nor a space

The bytes here are the ends of its four runs: ! / : @ [ ` { ~.

```cu
(hx (list "tr" "-d" "[:punct:]") (bytes->str (list 33 47 58 64 91 96 123 126 97 10)))
```
---
    61 0a | status 0

### a class in SET1 against a shorter SET2, and -c -d over [:print:]

```cu
(do (hx (list "tr" "[:digit:]" "x") in) (hx (list "tr" "-c" "-d" "[:print:]") in) (hx (list "tr" "-s" "[:space:]" " ") in))
```
---
```output
61 42 78 20 2e 09 7a 7e 0a | status 0
61 42 33 20 2e 7a 7e | status 0
61 42 33 20 2e 20 7a 7e 20 | status 0
```

## the other bracket forms

### [c*n] is n copies of c, [c*] is as many as SET1 needs, and [=c=] is c itself

The [=a=] input holds the brackets too, so a set that read them as bytes of
their own would map all of them.

```cu
(do (hx (list "tr" "abz" "[y*3]") in) (hx (list "tr" "a-z" "[x*]") in) (hx (list "tr" "[=a=]" "X") (bytes->str (list 91 61 97 61 93 98 10))))
```
---
```output
79 42 33 20 2e 09 79 7e 0a | status 0
78 42 33 20 2e 09 78 7e 0a | status 0
5b 3d 58 3d 5d 62 0a | status 0
```

### the count says how many, so what follows lines up with the rest of SET1

```cu
(do (hx (list "tr" "abc" "[y*2]z") (bytes->str (list 97 98 99 10))) (hx (list "tr" "abc" "y[z*2]") (bytes->str (list 97 98 99 10))))
```
---
```output
79 79 7a 0a | status 0
79 7a 7a 0a | status 0
```

### a [ that opens none of the forms is a byte of its own

```cu
(do (hx (list "tr" "[" "x") in) (hx (list "tr" "[:lower:" "x") in))
```
---
```output
61 42 33 20 2e 09 7a 7e 0a | status 0
61 42 33 20 2e 09 7a 7e 0a | status 0
```

## what tr refuses

### a class it does not know, in either set

```cu
(do (hx (list "tr" "[:nosuch:]" "x") in) (hx (list "tr" "-d" "[:nosuch:]") in))
```
---
```output
 | tr: invalid character class 'nosuch'
status 1
 | tr: invalid character class 'nosuch'
status 1
```

### a class in SET2 that is neither upper nor lower

```cu
(hx (list "tr" "[:alpha:]" "[:digit:]") in)
```
---
```output
 | tr: when translating, the only character classes that may appear in
string2 are 'upper' and 'lower'
status 1
```
